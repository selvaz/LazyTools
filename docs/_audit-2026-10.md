# Documentation audit — October 2026

Audited 11 October 2026 in `LazyTools-docs`, branch `docs/engines-collaboration`,
from `origin/main` release **0.10.1** (`69957de`). All writes are in this worktree.
The website homepage and `_drafts/strengths-2026-10.md` were read only. Their
claims were checked against this source baseline, not inferred from private
orchestrator deployment or planned post-release APIs.

## Scope and evidence

Every documentation Markdown page and README was reviewed for imports, API
surfaces, version/maturity statements, provider inventory and obsolete prose.
`tools/audit_docs.py` scans every page, imports referenced LazyTools/LazyBridge
symbols and checks statically resolvable constructor keywords. Mkdocstrings
resolves the reference objects during strict build. The scan is not a general
proof that every old reference fragment or external-service example executes.
Untouched guides retain explicitly illustrative signatures/fragments.

The refreshed executable snippets are extracted from Markdown in
`tests/test_docs_examples.py`. Engine construction seams and runtime processes
are mocked; a guard refuses unmocked subprocesses except fixture Git and Python
unittest. The bridge uses real Store/job/lock/ticket/routing machinery with
thread workers replacing OS launches. Its writer modifies the toy repo, Codex
reviews via frozen opposite-engine routing, actual boundary checks execute and
the documented verification helper records acceptance. MCP configuration and
provider expansion are exercised; optional portfolio dependencies use mocks.
Install commands are checked as PEP 508 requirements against declared extras,
without installing packages. No paid runtime or live telemetry call is made.

## Boundaries retained

Review exhaustion is not acceptance; reviewers that did not run are errors.
Owner labels are not ACLs. Admission gates new work, not running processes.
Bridge routing is operator-directed and has no project attribution; Python
route/recommend default to autonomous admission. A project cost report does not
automatically attribute bridge jobs or turn unmeasured subscription calls into
zero spend. Workspace evidence is best-effort for the whole repository,
including pre-existing changes; unreachable-from-start commits do not prove
job authorship. Timeout/cancellation do not provide automatic retry/resume.
The router selects the first eligible rung, with provisional tie-breaking;
**Benchmark in progress** carries no measured quality/time/savings result.
